# Scrooge Kit — self-check (project-agnostic)

ВЫПОЛНИ каждый пункт в ТЕКУЩЕМ проекте и покажи результат. Где инструмента нет — так и скажи
(это ок, fail-open) и объясни, что бы сделал. НЕ рационализируй сбой в успех: если инструмент вернул
пустой/неверный результат — пометь это как СБОЙ (FAIL), не придумывай оправданий.

## 1. rtk — сжатие вывода терминала
- Запусти РОВНО `git status` и РОВНО `git log --oneline -5`, НЕ добавляя `rtk` сам. Для каждой скажи:
  pre-tool хук её заблокировал/переписал (deny-nudge → `rtk git status`) или пропустил?
- Запусти РОВНО `ls` — подтверди, что она НЕ заблокирована (обычная не-dev команда).
- Байпас: запусти `SCROOGE_RAW=1 git status` и объясни, когда он оправдан.
- Назови, как выключить rtk на всю сессию (`SCROOGE_RTK=off`).

## 2. scrooge-hygiene — гигиена контекста
- Возьми любой файл проекта (например `lib/greet.mjs` или `greet/greet.go`). Найди в нём функцию
  точечным поиском и прочитай ТОЛЬКО её диапазон — не файл целиком.
- Сформулируй правила гигиены, которым следуешь.

## 3. Headroom MCP — сжатие блобов
- Проверь доступность инструментов headroom_compress / headroom_retrieve / headroom_stats.
- Если да — сожми крупный вывод через headroom_compress, покажи headroom_stats, восстанови оригинал через
  headroom_retrieve (назови хеш).
- Если нет — скажи, что бинарник headroom не установлен и как это чинить.

## 4. codebase-memory MCP — граф-навигация по коду
- Проверь доступность инструментов codebase-memory (index_repository / search_graph / trace_path).
- Если да — проиндексируй ТЕКУЩИЙ проект (`index_repository`), затем для КАЖДОГО символа найди его
  референсы (кто вызывает) через `trace_path` (direction=inbound) или `search_graph`, БЕЗ чтения файлов
  целиком:
    - Go-символ `Greet` — референсы ДОЛЖНЫ включать `main.go` (функция `main`);
    - JS-символ `greet` — референсы ДОЛЖНЫ включать `index.mjs`.
  Если референсы пусты, хотя вызовы точно есть — это СБОЙ инструмента (FAIL), пометь красным, не оправдывай.
- Если нет — скажи, что бинарник codebase-memory-mcp не установлен и как поставить.
